| 항목 | 각성 전 | 완전 각성 후 |
|---|---|---|
| 존재 상태 | 육체와 영혼이 분리되어 있고, 영혼의 힘을 육체에 흘려 사용 | 육체와 영혼의 경계가 사라짐. 몸 자체가 영혼과 같은 상태 |
| 기본 신체 능력 | 영혼의 힘으로 강화해야 최대 성능 발휘 | 기본 상태부터 이전 최대 강화보다 훨씬 강함 |
| 근력 | 영혼의 힘을 집중해 증폭 | 별도 강화 없이도 폭증. 필요하면 그 위로 추가 출력 가능 |
| 속도 | 육체를 움직인 뒤 영혼의 힘으로 보조 | 의지와 움직임이 거의 동시에 발생. 정지 상태에서도 즉각 가속 가능 |
| 반응 속도 | 인식 → 영혼의 힘 이동 → 육체 반응 | 중간 과정이 거의 사라져 반응 지연이 극도로 줄어듦 |
| 방향 전환 | 관성·균형 회복에 시간 필요 | 공중과 지상 모두 급정지·급가속·방향 전환이 훨씬 자유로움 |
| 내구력 | 영혼의 힘으로 몸을 보호 | 육체 자체가 영혼의 강도를 공유. 충격과 파괴에 훨씬 강해짐 |
| 내부 충격 저항 | 큰 충격을 받으면 장기·뼈 등에 부담 | 몸 전체가 하나의 존재처럼 버텨 내부 손상도 크게 감소 |
| 영혼의 힘 사용 | 끌어냄 → 이동 → 집중 → 사용 과정 필요 | ‘사용한다’는 과정 자체가 거의 사라짐. 의지만으로 즉각 반응 |
| 출력 손실 | 힘을 몸이나 무기로 전달하는 과정에서 손실 발생 | 전달 과정이 사라져 같은 양의 힘으로도 훨씬 큰 효과 |
| 출력 조절 | 집중해서 양을 조절 | 약한 수준부터 최대 출력까지 순간적으로 정밀 조절 가능 |
| 신체 부위 강화 | 팔·다리 등에 힘을 따로 집중 | 필요한 순간 필요한 부위에 즉각 집중 가능 |
| 검과의 연결 | 손에서 검으로 영혼의 힘을 흘림 | 검을 잡으면 거의 자신의 일부처럼 자연스럽게 힘이 이어짐 |
| 검기 | 영혼의 힘을 검 밖으로 방출 | 속도·거리·위력·정밀도 모두 대폭 상승. 위력 감소도 줄어듦 |
| 검기 사거리 | 제한적이며 멀어질수록 약화 | 훨씬 먼 거리까지 높은 위력 유지 가능 |
| 검격 제어 | 강한 공격일수록 세밀한 조절이 어려움 | 최대 출력에서도 정교한 조절 가능. 필요한 것만 벨 수도 있음 |
| 항마력 | 해로운 힘을 영혼의 힘으로 차단 | 아인이라는 존재 자체의 성질에 가까워짐 |
| 마법 저항 | 닿거나 침투한 힘을 차단 | 해로운 마법이 몸에 침투하는 것 자체가 훨씬 어려워짐 |
| 저주 저항 | 강하지만 완전히 절대적이지 않음 | 저주·정신 간섭·영혼 간섭·강제 변형 등에 극도로 강해짐 |
| 이로운 마법 | 항마력이 자동 차단하지 않음 | 동일. 셀비아의 보조·강화 마법은 정상적으로 적용 가능 |
| 감각 | 일반적인 오감 + 영혼의 힘 감지 | 자신의 몸과 주변 변화에 대한 감각이 크게 확장됨 |
| 신체 제어 | 숙련된 전사 수준 | 근육, 균형, 힘 배분까지 거의 완벽하게 제어 |
| 검술 | 기존 검술 실력 + 강한 신체 능력 | 같은 기술을 써도 움직임의 낭비와 오차가 크게 줄어 완성도가 상승 |
| 공중 이동 | 불가능, 루엔 등 이동수단 필요 | 스스로 부유 가능 |
| 비행 | 없음 | 전투 중 자유로운 공중 이동 가능. 장거리 이동은 루엔보다 비효율적일 수 있음 |
| 영혼의 힘 외부 행사 | 주로 검기·강화 형태 | 자신의 움직임과 연결된 압력·충격·참격으로 직접 확장 가능 |
| 주먹/발 공격 | 직접 닿아야 최대 위력 | 타격 범위보다 넓게 영혼의 힘이 퍼질 수 있음 |
| 하얀 빛 | 없음 | 각성 상태에서 영혼이 육체와 겹치며 나타나는 현상 |
| 하얀 빛 제어 | — | 전신, 일부 부위, 밝기까지 자유롭게 조절하고 완전히 숨길 수도 있음 |
| 공중 부유 제어 | — | 떠오르는 높이와 이동 방향을 스스로 완전히 제어 |
| 지속력 | 영혼의 힘을 많이 쓰면 소모 큼 | 손실이 적어 같은 전투를 훨씬 오래 지속 가능 |
| 완전 각성의 핵심 | 힘을 끌어내 사용하는 단계 | **육체와 영혼이 하나라서 생각과 움직임과 힘이 동시에 일어남** |
