자동 전투 기반 슈팅 게임 구현 보고서

1. 게임 개요

본 프로젝트는 Unity 6를 활용하여 제작한 간단한 자동 전투 슈팅 게임이다.
플레이어는 WASD 키를 이용하여 맵을 자유롭게 이동할 수 있으며, 주변에
존재하는 몬스터를 자동으로 탐지하고 투사체를 발사하여 공격한다. 몬스터는
플레이어를 단순히 추적하지 않고 BFS(Breadth First Search) 알고리즘을
활용하여 플레이어로부터 가장 멀어질 수 있는 경로를 탐색하며 도망친다.
이를 통해 플레이어는 이동과 위치 선정에 집중하고, 게임 내 AI는 탐색
알고리즘을 기반으로 독립적으로 행동하도록 구현하였다.

------------------------------------------------------------------------

2. 조작 방법

플레이어 이동

  키   기능
  ---- -----------
  W    전진
  S    후진
  A    좌측 이동
  D    우측 이동

플레이어 이동은 Unity Rigidbody의 AddForce()를 이용하여 구현하였다.

------------------------------------------------------------------------

3. 구현 기능

3-1. 몬스터 탐지 시스템

플레이어는 일정 범위 내에 존재하는 몬스터를 자동으로 탐지한다.

탐지 과정은 다음과 같다.

1.  Physics.OverlapSphere()를 사용하여 범위 내 Collider 검색
2.  LayerMask를 통해 몬스터 레이어만 필터링
3.  sqrMagnitude를 사용하여 가장 가까운 대상 탐색
4.  발견된 몬스터를 현재 타겟으로 지정

탐지 범위 내에 몬스터가 존재하면 자동 공격이 시작된다.

------------------------------------------------------------------------

3-2. 자동 조준 및 회전

타겟이 지정되면 플레이어는 해당 몬스터 방향으로 회전한다.

Quaternion.LookRotation()을 이용하여 목표 회전값을 계산하고,

Quaternion.Slerp()를 사용하여 자연스럽고 부드러운 회전을 구현하였다.

몬스터 또한 동일한 회전 방식을 사용하여 플레이어의 반대방향을 바라본다.

------------------------------------------------------------------------

3-3. 자동 투사체 공격

플레이어는 공격 주기마다 현재 타겟을 향해 투사체를 생성한다.

투사체는 Instantiate()를 이용하여 프리팹을 복제하여 생성되며
Rigidbody.linearVelocity를 사용하여 목표 방향으로 이동한다.

투사체가 몬스터와 충돌하면 다음 동작을 수행한다.

1.  “남은 체력 : {currentHp}”로그 출력
2.  남은 체력이 0이 되면 “타겟 격추!” 로그 출력
3.  몬스터 제거
4.  투사체 제거

충돌 판정은 OnTriggerEnter()를 이용하여 구현하였다.

------------------------------------------------------------------------

3-4. 거리 판정

몬스터 탐지 및 공격 범위 계산에는 sqrMagnitude를 사용하였다.

예시:

distance² < attackRange²

------------------------------------------------------------------------

3-5. BFS 기반 몬스터 도주 AI

몬스터는 플레이어를 향해 이동하지 않고 플레이어로부터 최대한 멀어지도록
행동한다.

이를 위해 BFS(Breadth First Search)를 사용하였다.

탐색 과정은 다음과 같다.

1.  현재 위치를 시작 노드로 설정
2.  상하좌우 노드를 Queue에 저장
3.  방문한 노드는 HashSet으로 관리
4.  탐색 가능한 노드를 순차적으로 조사
5.  플레이어와의 거리가 가장 먼 노드를 선택
6.  해당 위치로 이동

------------------------------------------------------------------------

------------------------------------------------------------------------

3-6. 인벤토리 및 아이템 강화 시스템

몬스터 처치 시 아이템을 획득할 수 있는 인벤토리 시스템을 구현하였다.

아이템 정보는 ScriptableObject 기반의 ItemData를 활용하여 관리하였으며,
아이템 이름, 아이콘, 능력치 효과 등을 저장하도록 설계하였다.

몬스터는 MonsterDropper 컴포넌트를 통해 드랍 가능한 아이템 목록과 드랍
확률을 보유한다. 몬스터가 사망하면 드랍 테이블을 참조하여 아이템 지급
여부를 결정한다.

획득한 아이템은 AutoItemCollector를 통해 자동으로 플레이어에게 지급되며,
PlayerInventory에서 관리된다.

인벤토리는 Dictionary<ItemData, int> 구조를 사용하여 아이템 종류와 보유
개수를 관리한다.

아이템 획득 과정은 다음과 같다.

몬스터 처치 ↓ 아이템 드랍 ↓ 자동 획득 ↓ 인벤토리 저장 ↓ 아이템 효과 적용
↓ 공격 사거리 증가

공격 사거리 증가 아이템을 획득하면 PlayerAttack 컴포넌트의 공격 범위
수치가 증가하도록 구현하였다.

이를 통해 플레이어는 몬스터를 처치할수록 더욱 넓은 범위에서 적을 공격할
수 있으며, 반복 플레이를 통한 성장 요소를 구현하였다.

4. 사용한 알고리즘

BFS (Breadth First Search)

BFS는 가까운 노드부터 순차적으로 탐색하는 그래프 탐색 알고리즘이다. 본
프로젝트에서는 몬스터가 이동 가능한 위치를 조사하여 가장 안전한 위치를
찾는 데 사용하였다.

장점

-   구현이 단순함
-   가까운 영역 탐색에 적합
-   경로 탐색 결과가 안정적임

사용 목적

플레이어를 피해 이동하는 몬스터 AI 구현

------------------------------------------------------------------------

5. 사용한 자료구조

Queue

BFS 구현을 위해 사용하였다.

특징

-   FIFO(First In First Out)
-   먼저 탐색한 노드를 먼저 처리

사용 이유

BFS의 레벨 순회 구조를 구현하기 위해 필요하다.

------------------------------------------------------------------------

HashSet

방문한 노드를 기록하기 위해 사용하였다.

특징

-   중복 저장 불가
-   빠른 탐색 가능

사용 이유

이미 방문한 노드를 다시 탐색하는 것을 방지하여 성능을 향상시키기
위함이다.

------------------------------------------------------------------------

LayerMask

몬스터 판별을 위해 사용하였다.

특징

-   특정 레이어만 필터링 가능
-   불필요한 충돌 검사 감소

사용 이유

몬스터만 탐지하여 성능을 최적화하기 위함이다.

------------------------------------------------------------------------

Dictionary

인벤토리 시스템 구현을 위해 사용하였다.

특징

-   Key-Value 형태의 데이터 저장
-   빠른 검색 및 수정 가능
-   동일 아이템의 수량 관리에 적합

사용 이유

아이템 종류와 보유 개수를 효율적으로 관리하기 위해 사용하였다.

예시

슬라임 젤리 → 3 포션 → 2 공격 사거리 룬 → 1

평균적으로 O(1)의 시간 복잡도로 아이템 검색 및 수량 갱신이 가능하여
인벤토리 관리에 적합하다.

------------------------------------------------------------------------

6. 물리 시스템 활용

Rigidbody

플레이어 이동

-   AddForce()
-   ForceMode

투사체 이동

-   linearVelocity

에 사용하였다.

------------------------------------------------------------------------

Collider

충돌 감지를 담당한다.

투사체와 몬스터의 충돌 시 Trigger 이벤트를 발생시킨다.

------------------------------------------------------------------------

Trigger 이벤트 흐름

투사체 진입 ↓ OnTriggerEnter() ↓ 몬스터 체력 감소 ↓ 투사체 제거

------------------------------------------------------------------------

7. 결론

본 프로젝트에서는 Unity 물리 시스템과 BFS 알고리즘을 활용하여 자동 전투
기반 슈팅 게임을 구현하였다. 플레이어는 직접 이동하며 전투 위치를
조절하고, 자동 공격 시스템은 적을 탐지하여 지속적으로 투사체를 발사한다.
몬스터는 BFS 기반 탐색을 통해 플레이어를 피해 이동하며 단순 추적 AI보다
다양한 행동 패턴을 보여준다. 이를 통해 Rigidbody, Collider, LayerMask,
BFS, Queue, HashSet 등의 핵심 개념을 실제 게임 제작 과정에 적용할 수
있었다.
